# تطبيق «الشارده ستور» (Alsharida Store) — React Native + Expo

تطبيق أندرويد أصلي بالكامل مبني بـ **React Native + Expo SDK 58 + TypeScript + Expo Router** لمنظومة **متجر النفار / الشارده ستور**. يتصل التطبيق مباشرة بواجهة البرمجة الخلفية (`Express` على `Vercel`) دون أي عرض لصفحات ويب داخلية.

---

## 1. المميزات والمكونات المنفّذة

- **بوابة الفروع ووضع الضيف (`BranchGate`)**: اختيار الفرع الأقرب عند أول تشغيل مع حفظه محلياً وإمكانية تبديله في أي وقت.
- **متجر الزبون (`/(store)`)**:
  - شريط **الأكثر طلباً (`TopList`)** من إحصائيات المبيعات العامة.
  - استعراض الألعاب بشبكة سريعة (`FlashList` + `expo-image`) مع البحث اللحظي والفلاتر (الفئة، النوع، السلسلة، الحروف الأبجدية `أ–ي` و`#`، وألعاب **تقسيم الشاشة**).
  - اختيار النسخة (**الفور PS4** / **الفايف PS5**) لألعاب فئة PS4، والإضافة المباشرة بالسعر الصحيح لبقية الفئات.
  - نافذة **الخدمات الإضافية (`ServicesSheet`)** لإضافة الخدمات مباشرة إلى السلة.
  - شاشة **الباقات (`packages.tsx`)** مع نافذة **«عرض الألعاب»** قبل الإضافة إلى السلة.
  - شاشة **السلة (`cart.tsx`)** بحساب الحجم الإجمالي بالـ GB والوقت التقديري للتجهيز، وإرسال الطلب للخادم أو عبر واتساب الفرع المختار.
- **تتبع الطلبات والإشعارات (`/track/[id]`)**:
  - تحديث تلقائي كل 30 ثانية ومؤشر خطوات التجهيز الثلاث (**تم الاستلام ← جاري التجهيز ← جاهز للاستلام**).
  - نافذة **مسح رمز QR (`QrScannerModal`)** بالكاميرا (`expo-camera`) من الفاتورة الورقية أو إدخال رقم الفاتورة يدوياً.
  - إشعارات حالة الطلب عبر `expo-notifications` (قنوات أندرويد + تنبيه محلي عند تغيّر الحالة + تسجيل توكن الجهاز).
  - تحكم فوري للموظف المسجّل دخوله لتغيير حالة الطلب أو تعليم الألعاب كمثبّتة (`installed`).
- **الفواتير والطباعة الحرارية (`src/print/PrinterDriver.ts` و`NativeReceiptModal.tsx`)**:
  - شاشة إيصال فاتورة أصلية بالكامل مع توليد رمز QR أصلي (`react-native-qrcode-svg`) وقراءة اسم المتجر والعنوان وعرض الورق (`58/80/100 مم`) من `/api/invoice-settings`.
  - واجهة طباعة موحدة (`PrinterDriver`) تدعم طباعة النظام وتصدير/مشاركة ملفات PDF عبر `expo-print` و`expo-sharing` مع تعليم الفاتورة كمطبوعة.
- **لوحة الإدارة (`/(admin)`) بتبويبات سفلية**:
  1. **الفواتير (`index.tsx`)**: فلترة بالتاريخ والآجل المرحّل، تسديد دفعات مفردة أو **تسديد الكل**، إرجاع لغير مدفوع، تعديل الفاتورة في المتجر، والطباعة.
  2. **الجرد اليومي (`daily-report.tsx`)**: ملخص المبيعات والخصومات والصافي والآجل، حالة الترقيم اليومي وتصفيره، إغلاق الجرد اليومي بملاحظة، وسجل الأيام السابقة.
  3. **الألعاب (`games.tsx` + `GameEditorModal.tsx`)**: إضافة وتعديل وحذف الألعاب، تكيّف حقول أسعار الفور/الفايف حسب الفئة، تصوير ورفع الغلاف عبر `/api/uploads`، والتعبئة الذكية عبر **Gemini AI** (`recognize-game`, `classify-by-title`, `analyze-game-genre`).
  4. **الأقسام (`catalog.tsx` + `PackageEditorModal.tsx`)**: إدارة الباقات وألعابها، التصنيفات، الخدمات، والأنواع والسلاسل.
  5. **الإعدادات والإحصائيات (`more.tsx` + `UsersBranchesSection.tsx`)**: لوحة الإحصائيات، إعدادات الفاتورة الحرارية، إدارة المستخدمين، إدارة الفروع (للمدير الرئيسي + شريط التبديل بين الفروع)، وسجل النشاط (`Audit Logs`).

## 2. متغيرات البيئة (`.env`)

لا يحتوي التطبيق على أي مفاتيح سرية. انسخ `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

المتغير الوحيد المستخدم:

```env
EXPO_PUBLIC_API_BASE=https://alnafar-store.vercel.app/api
```

---

## 3. التشغيل والفحص محلياً

```bash
# تثبيت الحزم المتوافقة مع Expo SDK
npx expo install

# فحص الأنواع (TypeScript)
npx tsc --noEmit

# تشغيل خادم التطوير
npx expo start
```

---

## 4. البناء عبر EAS (أندرويد)

ملف `eas.json` مهيأ بثلاثة ملفات تعريف (`development` لـ Dev Client، و`preview` لملف APK، و`production` لملف AAB لمتجر Google Play):

```bash
# بناء نسخة معاينة APK للتثبيت المباشر على أجهزة أندرويد
npx eas-cli@latest build --platform android --profile preview

# بناء نسخة الإنتاج لمتجر Google Play
npx eas-cli@latest build --platform android --profile production
```

---

## 5. اختبارات المسارات (Maestro E2E)

توجد مسارات الاختبار الآلي في مجلد `.maestro/`:

```bash
maestro test .maestro/store_and_track_flow.yaml
maestro test .maestro/staff_login_flow.yaml
```
