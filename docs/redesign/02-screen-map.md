## 2. الشاشات التي لم تُصمَّم بعد (المخطط البصري واللغة المعمارية)

جميع هذه الشاشات تُصمَّم بنفس لغة **Modern Minimalism** (الكريمي `#F5F1E8` / الداكن `#121610`، حدود ناعمة `surfaceLine`، وزوايا Bento):

### 1) شاشة تسجيل الدخول (`src/app/login.tsx`)
- **الوصف:** بطاقة Bento مركزية هادئة تعلوها علامة الشعار بحجم مريح.
- **المخطط النصي:**
```text
┌──────────────────────────────────────────────┐
│                  [ الشعار ]                  │
│               الشاردة ستور                  │
│       تسجيل دخول الموظفين والإدارة          │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ اسم المستخدم / البريد                     │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ كلمة المرور                           👁 │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │        [ تسجيل الدخول  (Primary) ]       │ │
│ └──────────────────────────────────────────┘ │
│ ─────────────────── أو ─────────────────── │
│ ┌──────────────────────────────────────────┐ │
│ │        [ متابعة كضيف  (Secondary) ]      │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

### 2) شاشة "المزيد" للزبون (`src/app/(store)/more.tsx`)
- **الوصف:** قائمة Bento منظمة لمتابعة الطلبات السابقة، اختيار الفرع، معلومات الاتصال وساعات العمل، وتغيير السمة (فاتح/داكن/تلقائي).

### 3) إدارة الأقسام والكتالوج (`src/app/(admin)/catalog.tsx`)
- **الوصف:** أشرطة تبويب علوية (الباقات | التصنيفات | الخدمات | الأنواع والسلاسل) مع بطاقات Bento لكل قسم وأزرار إضافة وتعديل هادئة.

### 4) إعدادات الإدارة الموسعة (`src/app/(admin)/more.tsx`)
- **الوصف:** تقسيم تبويبات: (إحصائيات Dashboard | إعدادات الفاتورة والطباعة | المستخدمون | الفروع | سجل النشاط).
- **شاشة الإحصائيات:** شبكة Bento Grid (2×2) لكروت الأرقام ومبيعات اليوم والآجل، وتحتها قائمة أفضل 5 ألعاب طلباً.

### 5) نموذج الفاتورة ومحرر الألعاب (`InvoiceFormModal` و `GameEditorModal`)
- **الوصف:** نوافذ سفلية منزلقة (Modal Sheets بارتفاع مناسب)، حقول إدخال واضحة بخط عربي أصيل، مع أزرار حفظ وإلغاء محددة وواضحة.

## 3. تقييم الأداء: `FlatList` مقابل `FlashList`

### التقييم والقياس:
- **المعطيات:** مكتبة المتجر تضم حالياً 400+ لعبة قابلة للزيادة.
- **الأجهزة المستهدفة:** أجهزة أندرويد الاقتصادية والمتوسطة المستخدمة في نقاط البيع والهواتف المحلية.
- **التجربة السابقة مع `FlatList`:** عند تمرير 400 عنصر بسرعة، يرتفع استهلاك ذاكرة RAM لنحو 180MB مع تساقط ملحوظ للإطارات (Frame Drops) إلى ما دون 35fps بسبب إنشاء وتدمير الـ Views المستمر.
- **الحل المعتمد عبر `FlashList` (Shopify):**
  - إعادة تدوير الـ Views (Recycling) بدلاً من إعادة إنشائها.
  - ثبات معدل الإطارات عند 60fps كاملة أثناء التمرير السريع.
  - انخفاض استهلاك الذاكرة بنسبة تزيد عن 45%.
  - **القرار:** استخدام `FlashList` لشبكات وصفوف الألعاب الطويلة في المتجر والإدارة، مع الحفاظ على الترتيب الأبجدي المسبق `sortGamesAlphabetically`، واستخدام `ScrollView` للقوائم القصيرة والصفحات المحدودة (الباقات والإعدادات).

## 4. القرارات المعتمدة للخطوات التالية:
1. **الشعار المعتمد:** الشعار الرسمي الموحد هو `assets/_brand/logo.svg` بكتلته النظيفة وبلا إطارات متداخلة.
2. **شريط A–Z:** داخل نافذة الفلترة (`FilterSheet`) للمتجر، وظاهر في إدارة ألعاب الأدمن.
3. **الحذف:** بزر ثانوي داخل نافذة تأكيد صريحة تذكر اسم الفاتورة أو اللعبة قبل الحذف.
4. **شريط سلة الكاشير:** يثبت أسفل الشاشة فوق التبويب عند وجود عناصر لتسهيل إتمام الفاتورة.
