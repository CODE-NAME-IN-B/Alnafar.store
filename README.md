# 🎮 متجر النفار (Alnafar Store)

**متجر النفار** هو نظام حديث ومبتكر لإدارة عرض ومبيعات الألعاب الإلكترونية، يوفر واجهة مستخدم احترافية وجذابة صُممت خصيصاً لتسهيل عملية الاستكشاف للزبائن داخل المتجر.

---

### ✨ فكرة المشروع وآلية العرض
تعتمد فكرة المتجر على تقديم تجربة استعراض رقمية استثنائية وبسيطة:
- **استكشاف حر للضيوف:** يمكن لأي مستخدم الدخول "كضيف" لتصفح مكتبة الألعاب الواسعة بشكل كامل ومجاني دون الحاجة لامتلاك حساب في النظام.
- **باقات الألعاب التفاعلية:** بجانب شراء الألعاب بشكل منفرد، يوفر المتجر باقات اقتصادية. باستخدام زر **"عرض الألعاب"**، يستطيع الزبون الدخول للباقة ورؤية جميع الألعاب الموجودة بداخلها بمساحاتها وتفاصيلها ليكون على دراية كاملة بمشترياته.
- **تنظيم وفلترة ذكية:** يتيح النظام خيارات بحث متقدمة، سواء أكان البحث هجائياً، أم فرزاً حسب السلسلة (مثل Resident Evil أو FIFA)، أم نوع اللعبة (رعب، أكشن، منصات)، إلى جانب مؤشر للبحث الخاص بالألعاب التي تدعم "تقسيم الشاشة".
- **واجهة صديقة للمستخدم:** تم تصميم التجربة لتكون سلسة وواضحة، لتركز فقط على استعراض المحتوى والأسعار وتسهيل تجربة الشراء الحصرية في مكان البيع.

### 🛠️ التقنيات المستخدمة
تم الاعتماد على مكدس تقني حديث لتوفير استجابة سريعة وتصميم تفاعلي:
- **تطوير الواجهات:** تم البناء ليكون تطبيق ويب سريع التفاعل (SPA) لضمان عدم وجود بطء أثناء إضافة وتصفح البيانات.
- **التصميم المرئي:** تم أخذ التوافق الكامل مع الجوال والهواتف المحمولة وتوفير واجهة ليلية (Dark Mode) حديثة وانسيابية بالاعتماد على إطارات التصميم النفعية المتقدمة.
- **إدارة البيانات والخوادم:** تقنيات مبنية على بيئة عمل JavaScript للتعامل مع قاعدة البيانات وتوفير إحصائيات المبيعات، مع دعم للتحديثات الفورية (Real-time).
